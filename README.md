# Sistema de Iluminação Automática com Arduino

## Sobre o projeto

Este projeto consiste em um sistema de iluminação automática desenvolvido
com Arduino e sensores de presença.

O objetivo é automatizar a iluminação de um ambiente, acionando diferentes
luzes de acordo com a detecção de movimento.

## Funcionamento

O sistema utiliza sensores de presença para controlar as lâmpadas:

- Sensor 1 → controla a Luz 1
- Sensor 2 → controla a Luz 2
- Sensor 3 → controla as Luzes 3 e 4

Enquanto o sensor detectar presença, a iluminação permanece ligada.
Após o sensor deixar de detectar movimento, a luz permanece ligada por
10 segundos e então é desligada.

## Componentes

- Arduino
- 3 sensores de presença
- 4 LEDs/luzes
- Resistores
- Protoboard
- Fios de conexão
- Fonte de alimentação

## Tecnologias utilizadas

- Arduino
- C/C++
- Sensores de presença
